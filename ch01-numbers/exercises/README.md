# 練習問題 — 第1章 数と式

`docs/index.md` の内容を確認するための練習問題を置きます。

## ファイルの置き方（目安）

- `01-classification.md` — 数の分類
- `02-absolute-value.md` — 絶対値
- `03-expansion.md` — 式の展開
- `04-factorization.md` — 因数分解

各ファイルは「問題 → 解答・解説」の順にまとめ、解答は `<details>` で折りたたむと自習に使いやすい。

## 例

問1. 次の数を有理数と無理数に分類せよ。

$$
3,\quad \sqrt{2},\quad -\frac{5}{7},\quad \pi,\quad 0.25
$$

<details>
<summary>解答</summary>

- 有理数: $3,\ -\dfrac{5}{7},\ 0.25$
- 無理数: $\sqrt{2},\ \pi$

</details>
