# 課題 — 第1章 数と式

提出用の課題を置きます。練習問題（`exercises/`）が理解の確認用なのに対し、こちらは**成績評価に使う提出物**を想定します。

## 運用の目安

- 1 課題 = 1 ファイル（例: `assignment-01.md`）
- 各課題の先頭に **対象範囲 / 配点 / 提出期限 / 提出方法** を明記する
- 解答例は教員用に別途管理し、この公開ディレクトリには置かない

## テンプレート

```markdown
# 課題 01 — 数と式

- 対象範囲: docs/index.md 1.1〜1.3
- 配点: 20 点
- 提出期限: （日付）
- 提出方法: （LMS / Issue など）

## 問1（10 点）
...

## 問2（10 点）
...
```
