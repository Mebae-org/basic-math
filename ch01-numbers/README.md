# 第1章 数と式

## 概要

実数の体系を整理し、整式と分数式の四則演算、因数分解、絶対値、平方根、複素数を扱う。以降のすべての章の土台となる計算力を身につける。

## 学習目標

この章を終えると、次のことができるようになる。

- [ ] 自然数・整数・有理数・無理数・実数の包含関係を説明できる
- [ ] 絶対値の定義を理解し、簡単な絶対値を含む計算ができる
- [ ] 整式の加減乗除を正しく実行できる
- [ ] 乗法公式を用いて式を展開できる
- [ ] 基本公式・因数定理を使って整式を因数分解できる
- [ ] 分数式の定義域に注意して加減乗除ができる
- [ ] 平方根を簡単にし、分母を有理化できる
- [ ] 複素数の相等を理解し、加減乗除と絶対値を計算できる
