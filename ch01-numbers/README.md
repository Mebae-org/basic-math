# 第1章 数と式

## 概要

実数の体系を整理し、多項式の四則演算・展開・因数分解を扱う。以降のすべての章の土台となる計算力を身につける。

## 学習目標

この章を終えると、次のことができるようになる。

- [ ] 自然数・整数・有理数・無理数・実数の包含関係を説明できる
- [ ] 絶対値の定義を理解し、簡単な絶対値を含む計算ができる
- [ ] 多項式の加減乗を正しく実行できる
- [ ] 乗法公式を用いて式を展開できる
- [ ] 因数分解の基本手法（共通因数・公式・たすき掛け）を使い分けられる
