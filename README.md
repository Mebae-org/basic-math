# basic-math — 高専 基礎数学

高等専門学校の**基礎数学**を学ぶための教材リポジトリです。モデルコアカリキュラムの到達目標に沿って、各章に解説（`docs/`）・練習問題（`exercises/`）・提出課題（`assignments/`）をまとめています。

| [ch01-numbers](./ch01-numbers/) | 数と式 | 整式・分数式・絶対値・平方根・複素数 |
| [ch02-equations](./ch02-equations/) | 方程式と不等式 | 二次・高次・連立・無理・分数方程式、一次・二次不等式、恒等式 |
| [ch03-functions](./ch03-functions/) | 関数 | 二次関数・分数関数・無理関数・逆関数 |

## 教材本文の管理方針

このリポジトリでは、AIが整備する本文と、人間が自分の言葉で書く本文を同じ `docs/` ディレクトリに並べて管理する。

- `docs/index.md`: モデルコアカリキュラムを網羅するために、AIが作成・更新する共通の本文
- `docs/<任意のファイル名>.md`: 参加者が自分の構成や説明で自由に書く本文（例: `docs/takeruf.md`）

人間が書いたファイルをAI版の補足や下位の版として扱うのではなく、それぞれ異なる説明や視点をもつ教材として並列に置く。どのファイルもPull Requestとレビューを通じて、参加者同士で改善していく。

参加者は各章の `docs/` に自由なファイル名を付けたMarkdownファイルを追加できる。内容の構成、文体、例題の選び方などは自由とし、複数の人が教材を持ち寄って育てられる余地を残す。
