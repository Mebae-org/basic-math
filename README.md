# basic-math — 高専 基礎数学

高等専門学校の**基礎数学**を学ぶための教材リポジトリです。各章ごとに解説（`docs/`）・練習問題（`exercises/`）・課題（`assignments/`）をまとめています。

## 章一覧

| 章 | タイトル | 概要 |
|----|----------|------|
| [ch01-numbers](./ch01-numbers/) | 数と式 | 実数・式の計算・因数分解 |

（章は順次追加予定）
