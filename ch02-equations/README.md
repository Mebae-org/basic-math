# 第2章 方程式と不等式

## 概要

二次方程式と高次方程式、連立方程式、無理方程式・分数方程式を扱う。さらに、不等式の解法と恒等式の係数比較を学び、式の変形だけでなく定義域や同値性を意識して解を検証する力を身につける。

## 学習目標

この章を終えると、次のことができるようになる。

- [ ] 解の公式を用いて二次方程式を解き、判別式から実数解の個数を判断できる
- [ ] 因数定理を用いて高次方程式を因数分解して解ける
- [ ] 代入法・加減法を用いて連立方程式を解ける
- [ ] 無理方程式・分数方程式の定義域を確認し、得られた解を検算できる
- [ ] 一次不等式・二次不等式を解き、解集合を区間で表せる
- [ ] 恒等式と方程式を区別し、係数比較によって未知の係数を決定できる
