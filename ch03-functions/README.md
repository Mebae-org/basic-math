# 第3章 関数

## 概要

二次関数、分数関数（有理関数）、無理関数の性質とグラフを扱う。式、グラフ、定義域・値域を結びつけ、最大値・最小値や不等式を考察する。さらに逆関数を通して、入力と出力を入れ替える条件と方法を学ぶ。

## 学習目標

この章を終えると、次のことができるようになる。

- [ ] 二次関数の軸・頂点・切片を求めてグラフを描ける
- [ ] 定義域を考慮して二次関数の最大値・最小値を求められる
- [ ] 分数関数の定義域、漸近線、値域を調べてグラフを描ける
- [ ] 無理関数の定義域、値域、端点を調べてグラフを描ける
- [ ] 有理不等式・無理不等式を定義域と符号に注意して解ける
- [ ] 逆関数の存在条件を説明し、定義域・値域を入れ替えて逆関数を求められる
