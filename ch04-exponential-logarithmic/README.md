# 第4章 指数関数と対数関数

## 概要

$n$ 乗根と指数法則をもとに、指数を整数から有理数へ拡張する。指数関数と対数関数の定義・性質・グラフを理解し、方程式と不等式を定義域や底の範囲に注意して解く。

## 学習目標

この章を終えると、次のことができるようになる。

- [ ] $n$ 乗根の実数としての個数と性質を説明できる
- [ ] 指数法則を有理数指数まで用いて式を計算できる
- [ ] 指数関数のグラフと増減を底によって判断できる
- [ ] 指数方程式・指数不等式を共通の底や置換を用いて解ける
- [ ] 対数の定義と対数法則を用いて値や式を計算できる
- [ ] 対数関数の定義域、グラフ、増減を説明できる
- [ ] 対数方程式・対数不等式を真数条件と底の範囲に注意して解ける
