# 第7章 場合の数

## 概要

複雑な数え上げを、和の法則と積の法則に分解して考える。順序を区別する順列と、順序を区別しない組合せの違いを理解し、条件に応じて正しい方法で場合の数を計算する。

## 学習目標

この章を終えると、次のことができるようになる。

- [ ] 和の法則と積の法則を区別して使える
- [ ] 階乗を用いて順列の総数を計算できる
- [ ] 重複順列、同じものを含む順列、円順列を適切に計算できる
- [ ] 組合せの意味を説明し、総数を計算できる
- [ ] 順序を区別するかどうかを判断して順列と組合せを使い分けられる
