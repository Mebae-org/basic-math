# 第8章 数列

## 概要

規則に従って並ぶ数を数列として捉え、等差数列・等比数列の一般項と和を学ぶ。シグマ記号による和の表現と計算、数列の極限、無限等比級数の収束・発散までを扱う。

## 学習目標

この章を終えると、次のことができるようになる。

- [ ] 等差数列と等比数列の一般項を求められる
- [ ] 等差数列と等比数列の有限和を計算できる
- [ ] シグマ記号の意味を理解し、基本公式を用いて和を計算できる
- [ ] 数列の収束・発散を判定し、極限値を求められる
- [ ] 無限等比級数の収束条件を説明し、収束するときの和を求められる
