# 課題 — 第8章 数列

提出用の課題を置きます。練習問題（`exercises/`）が理解の確認用なのに対し、こちらは**成績評価に使う提出物**です。

## 運用の目安

- 1課題を1ファイルにまとめる
- 各課題の先頭に **対象範囲 / 配点 / 提出期限 / 提出方法** を明記する
- 答えだけでなく途中式・判定理由も採点する
- Issueへの提出内容を教員が手動で採点する
- 解答例と採点基準は教員用に別途管理し、この公開ディレクトリには置かない
