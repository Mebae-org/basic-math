# 第6章 図形と方程式

## 概要

平面上の点と図形を座標と方程式で表す。2点間の距離と内分点、直線・円・円錐曲線の方程式を学び、方程式や不等式から図形と領域を読み取る力を身につける。

## 学習目標

この章を終えると、次のことができるようになる。

- [ ] 2点間の距離と線分の内分点を求められる
- [ ] 条件から直線と円の方程式を立て、位置関係を調べられる
- [ ] 放物線・楕円・双曲線の標準形とグラフの形を対応づけられる
- [ ] 方程式を変形して図形の中心・頂点・軸などを読み取れる
- [ ] 不等式が表す領域を境界と代表点から判定できる
