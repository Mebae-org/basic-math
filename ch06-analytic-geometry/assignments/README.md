# 課題 — 第6章 図形と方程式

提出用の課題を置きます。練習問題（`exercises/`）が理解の確認用なのに対し、こちらは**成績評価に使う提出物**です。

## 運用方針

- 課題は [`assignment-06.md`](./assignment-06.md) を使用する
- 全5問、各問4点とする
- 各問には半角数字で整数を1つだけ入力し、単位、式、途中式は書かない
- GitHub Issue の提出フォームから提出すると、GitHub Actions が自動採点する
- 再挑戦する場合は、新しい Issue を作成して提出する
- 正解や解答例は公開リポジトリに置かない
