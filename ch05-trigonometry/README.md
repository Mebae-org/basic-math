# 第5章 三角関数

## 概要

弧度法を導入し、一般角に対する三角関数の値、性質、グラフを学ぶ。さらに、三角方程式・不等式と加法定理を扱い、角の情報を式として処理する力を身につける。

## 学習目標

この章を終えると、次のことができるようになる。

- [ ] 度数法と弧度法を相互に変換し、扇形の弧の長さと面積を求められる
- [ ] 単位円を用いて一般角の三角関数の値を求められる
- [ ] 三角関数の周期性・対称性を説明し、グラフを描ける
- [ ] 基本的な三角方程式と三角不等式を解ける
- [ ] 加法定理とその帰結を用いて三角関数の値や式を計算できる
